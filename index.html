GT4 Cam

Install the Linux camera viewer and Xbox driving controls on a Raspberry Pi 5 running Twister OS 3.x.

Add the repository

Download the public key and verify its fingerprint.

curl -fsSLO https://sirnugget11.github.io/gt4cam-apt/gt4cam-archive-keyring.gpg
gpg --show-keys --fingerprint gt4cam-archive-keyring.gpg

757C21D570FB4C2EF067CB83C4AAB9D67C3E2367

After the fingerprint matches, add the repository and install GT4 Cam.

sudo install -D -m 644 gt4cam-archive-keyring.gpg /etc/apt/keyrings/gt4cam.gpg
echo 'deb [signed-by=/etc/apt/keyrings/gt4cam.gpg] https://sirnugget11.github.io/gt4cam-apt ./' |
  sudo tee /etc/apt/sources.list.d/gt4cam.list >/dev/null
sudo apt update
sudo apt install gt4cam

Open GT4 Cam from the desktop menu. Updates are available through APT.
